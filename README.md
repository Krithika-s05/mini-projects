# Java Calculator

## About the Project
This project is a simple Calculator application developed using Java Swing. It provides a graphical user interface (GUI) that allows users to perform basic arithmetic operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- User-friendly GUI

## Technologies Used
- Java
- Java Swing
- VS Code

## How to Run
1. Clone this repository.
2. Open the project in VS Code or any Java IDE.
3. Compile the Java file.
4. Run `Calculator.java`.
